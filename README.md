# Сайт «Точка Счастья. Дети»

Одностраничный сайт иммерсивных игр-экскурсий для школьных классов (Москва).

- `index.html` - вся страница: стили, тексты и скрипты в одном файле.
- `media/` - картинки блоков (gen-01..13), ролик первого экрана, видеоотзывы, логотип.

## Как открыть
Открыть `index.html` в браузере. Для видео лучше через локальный сервер, например `python -m http.server`, и затем http://localhost:8000.

## Что внутри
- Колибри садится на каждый блок.
- Блоки встают на месте.
- Финал в подвале с возвратом наверх.
- Меню с переходом через размытие.

Подробные пояснения - в комментариях внутри `index.html`.
